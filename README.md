# ProCity Realty — Toronto Pre-Construction Directory

A responsive directory prototype for Toronto and GTA pre-construction condos and townhomes.

## Features

- Project directory with city, keyword, and property-type filters
- Sorting, saved-project interactions, and project detail dialogs
- Toronto, Vaughan, Markham, and Richmond Hill area discovery
- Responsive mobile navigation and layouts
- Lead-capture forms ready to connect to a CRM or Cloudflare Worker
- Static deployment with no build step

## Local preview

```bash
npx serve .
```
